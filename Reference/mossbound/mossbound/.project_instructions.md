# Mossbound — MOBA 2D indie (demo jogável)
- Idioma do usuário: português (todo texto do jogo em PT-BR). Prioridade: beleza gráfica e detalhes.
- Phaser 3.88 + TS em `src/game/` (config/balance, world/{MapLayout,Ambience}, graphics/* texturas pixel art geradas em canvas, audio/SoundManager Web Audio, entities/*, systems/*, ui/{Widgets,HUD,Minimap,Shop}, scenes Boot→Menu→Game(+UI em cena paralela)). Carregado só no cliente via components/phaser-game.tsx (import dinâmico) dentro de components/game-shell.tsx.
- Paleta: musgo #4a7c59/#2d5a3d, petróleo #1a4a5c, creme #f5e6c8, terracota #c17a4a, âmbar #ffb347 (primary), azul #00c8b4 (aliado), coral #ff6b6b (inimigo). Fonte Pixelify Sans. Tema dark padrão com tokens musgo/âmbar em :root e .dark.
- Painéis UI: textura canvas ladrilhada (Widgets.panel) — NÃO usar nineslice (borra pixel art).
- Controles: setas movem (WASD conflita com QWER), botão direito move até cursor, esquerdo = AA, Q/W/E/R habilidades, B teleporte 3s, P loja (abre sozinha na base), 1/2/3 compram, Esc pausa, clique no minimapa move.
- QA via Playwright em /home/ubuntu/qa/play.py.
